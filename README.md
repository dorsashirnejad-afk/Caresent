# CareSend – نسخه اولیه

این پوشه یک PWA موبایل‌محور برای آیفون است.

## تست ظاهر
فایل index.html را از طریق یک وب‌سرور HTTPS منتشر کنید و در Safari باز کنید.
سپس Share > Add to Home Screen را بزنید.

## ارسال واقعی SMS
فایل server-example.js اسکلت بک‌اند امن است. برای نسخه عملیاتی:
1. متن‌های مراقبتی را پزشک/مسئول کلینیک تأیید کند.
2. KAVENEGAR_API_KEY فقط در Secret/Environment Variable سرور ذخیره شود.
3. endpoint رسمی کاوه‌نگار طبق مستندات روز آن روی سرور پیاده‌سازی شود.
4. قالب‌ها سمت سرور نگهداری شوند و محدودیت نرخ ارسال/ثبت لاگ اضافه شود.

نکته: این نسخه عمداً API Key ندارد تا کلید شما داخل اپ آیفون افشا نشود.
